# Two Week Project

A standalone HTML project contained in `2weekproject.html`.

## Overview

This project is a simple web page built with HTML, CSS, and JavaScript in a single file. It can be opened directly in a browser without installing any dependencies.

## Project Structure

```text
.
├── 2weekproject.html
└── README.md
```

## How to Run

1. Open the project folder.
2. Double-click `2weekproject.html`.
3. The page will open in your default web browser.

You can also open it manually from a browser using:

```text
File > Open File > 2weekproject.html
```

## Technologies Used

- HTML
- CSS
- JavaScript

## Features

- Single-page web project
- No external setup required
- Runs locally in any modern browser

## Editing the Project

To make changes, open `2weekproject.html` in a code editor and edit the HTML, CSS, or JavaScript inside the file. After saving, refresh the browser to see the updated page.

## Notes

This project does not require Node.js, npm, or a development server unless additional tooling is added later.
